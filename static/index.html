File Download Agent 自托管下载中转

把地址变成一条下载链接

服务器代为中转。支持断点续传、有效期与签名校验。

生成下载链接

  • https:// ✓
  • http:// ✓
  • file:// ✓

填写主机名和路径，例如 example.com/file.zip；也可直接粘贴完整 URL。

服务器设置了 sign-key 时必填；未设置时留空即可。

打开

WebDAV 访问

地址
/webdav/
用户名
anonymous（默认）
密码
sign-key，或启动日志中的随机密码

使用说明

  • 支持 http、https 与 file:// 地址。
  • file:// 仅能访问服务器下载目录内的文件。
  • 有效期留空表示长期有效，过期后返回 403。
  • 签名密钥需与服务器 sign-key 一致，建议使用至少 16 位的随机字符串。
